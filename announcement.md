# Анонс GitLab MR Dashboard

Всем привет, особенно разработчикам! Наговнокодил приложение для отслеживания MR по своим проектам, особенно удобно, когда проектов несколько и хочется видеть все в одном месте.

**[Image #1]**

MR разбиты на 4 категории:
- **Needs your review** - MR, где ты еще не апрувнул, по отфильтрованным проектам
- **You approved** - MR, которые ты уже апрувнул
- **Your open MRs** - твои собственные открытые MR
- **Mentioned you** - MR, в которых тебя упомянули

По каждому MR видно: кто апрувнул, статус пайплайна с переходом прямо в него.

**[Image #2]**

Прямо в интерфейсе можно посмотреть треды - комментарии и дискуссии по MR.

**[Image #3]**

После твоего апрува в категории "You approved" подсвечиваются новые коммиты и новые треды, которые появились уже после того, как ты апрувнул. Удобно следить, не сломал ли автор что-то после ревью.

Из приложения можно перейти прямо в MR в GitLab.

**[Image #4]**

Помимо открытых MR, можно смотреть Merged и Closed с поиском и фильтрами.

**[Image #5]**

Можно выставить фильтр только по интересующим тебя проектам из всех, к которым у тебя есть доступ.

Для доступа нужен только GitLab-токен с разрешением `api`.
